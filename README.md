# S-P-global-dashboard
# S&P Global (NYSE: SPGI) — FY2025 performance dashboard

An interactive dashboard built from S&P Global's published filings: revenue, division results, margins, capital returns and the 2026 outlook after the Mobility spin-off.

**Live site:** `https://subhan172.github.io/S-P-global-dashboard/`

## What's in this repository

| File | Purpose |
|---|---|
| `index.html` | The dashboard. One file, no build step, no internet connection needed. |
| `SPGI_dashboard_1_overview.png` | Poster board 1 — FY2025 scorecard |
| `SPGI_dashboard_2_divisions.png` | Poster board 2 — division deep dive |
| `SPGI_dashboard_3_capital_outlook.png` | Poster board 3 — cash, shareholders and outlook |
| `SPGI_dashboard_dataset.xlsx` | The underlying tables, ready to load into Power BI or Excel |



## Sources

S&P Global 4Q and FY2025 earnings release (10 February 2026); FY2025 Form 10-K; Q2 2026 earnings release (28 July 2026); Form 8-K dated 6 July 2026; S&P Global Investor Fact Book. Market data as at 26 August 2026.

FY2025 figures include the Mobility division. Mobility was spun off as Mobility Global (NYSE: MBGL) on 1 July 2026, so every 2026 pro forma figure excludes it.

Compiled for analysis and learning. Not investment advice.
